# 金のフレーズ 単語カード

「TOEIC L&R TEST 出る単 金のフレーズ」の単語を覚えるための、自分用のフラッシュカードアプリです。
素のHTML/CSS/JavaScriptの単一ファイルで動き、外部ライブラリ・外部通信はありません。
PWAとしてiPhoneのホーム画面に追加すると、オフラインでも使えます。

## 機能
- 単語／例文／派生語①②／間違えた問題の出題（制限時間・習得判定つき）
- セクションごとの到達度表示（100%で金色と👑）
- 単語の追加、学習記録のバックアップ・復元（JSON）
- 登録語数：1,783語（本編001〜1000、Supplement、Column）

## 構成
```
.
├── index.html        アプリ本体（CSS・JS・単語データ SEEDS を内蔵）
├── manifest.json     PWA設定（名前・アイコン・表示方法）
├── sw.js             Service Worker（オフライン用キャッシュ）
├── icon-180.png      ホーム画面用アイコン
├── icon-192.png      同上
├── icon-512.png      同上
├── check.js          読み込みテスト（各セクションの語数を点検）
├── .gitignore
└── README.md
```

## 使い方
- **PC**：`index.html` をブラウザで開く。
- **iPhone**：GitHub Pages で公開したURLをSafariで開く → 共有ボタン →「ホーム画面に追加」 → ネットにつながった状態でアイコンから一度開く（以降はオフライン可）。

## GitHub Pages で公開する
1. リポジトリを作成し、上記の中身をすべてアップロード
2. Settings → Pages → Branch を `main`、フォルダを `/(root)` にして Save
3. 表示されたURL（`https://ユーザー名.github.io/リポジトリ名/`）を開く

## 更新するとき
1. 変更したファイルを同じリポジトリに上書きアップロード
2. `sw.js` の先頭にある `kinphrase-v3` の番号を上げる（上げないと古い版が使われ続けます）
3. iPhoneはネットにつながった状態で、アプリを開き直す

## データの保存について
- 学習記録は、そのブラウザ（ホーム画面のアプリとSafariは別）の localStorage に保存されます。
- 端末をまたぐ移行は、ホームの「データの保存・復元」でJSON文字列をコピー／貼り付けします。
- ブラウザのサイトデータ削除やプライベートモードでは記録が消えます。定期的なバックアップをおすすめします。

## 点検
```
node check.js index.html
```
結果は `out.txt` に出ます（セクション名・語数・最初と最後の番号・例文数・派生語数・TOTAL）。
